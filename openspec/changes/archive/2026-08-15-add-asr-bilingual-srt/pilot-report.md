## ⚠️ Claude 引擎污染事件（本試點最大方法學缺陷）

批次翻譯的 subagent 為了統一拼法，讀了同目錄的另一方向批次檔——
等於 f2z 翻譯時看到了字幕「答案」（b06 的 agent 自己承認，b01–b03
也提到參考）。後果：

- 47 個條目呈污染特徵（claude 條目分數 ≥0.6 而 ailabs <0.2）；
- max-取高規則讓這些 ASR 其實無效的條目被放行成 ok（雙引擎 ok 150
  vs 僅 ailabs 33 的落差主要來自此）；
- 兩引擎「互相一致度」平均 0.141 因此**不可當獨立互證解讀**。

**已修正（重譯完成）**：16 批全部以隔離規則重翻——每批獨立資料夾
只放自己的輸入、拼法表隨 prompt 附上、明令整個任務只准 Read＋Write
各一次，並以每個 agent 的工具呼叫計數稽核（16/16 恰好 2 次，含 4
個因用量上限斷線但已寫完檔的，由 transcript 計數補驗）。重跑後
污染特徵條目 47 → 0。
