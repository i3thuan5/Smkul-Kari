# tests/mt/：族語新聞平行語料的測試

`scripts/mt/`：把 sapolita 族語辨識段落跟華語燒印字幕配成段落級的平行語料（計算引擎）。
`test_lexicon.py`、`test_run.py` 測的是 `scripts/news/lexicon_fetch.py`、`pairs_run.py`，
這條線的測試集中在這裡讀。

檔名鏡射模組名；這張表照流程排。scenario 寫的是量到的資料性質與踩過的
坑，來源優先序「自己踩過的坑 ＞ 量測到的資料性質 ＞ spec 條文」。

| 模組 | scenario | 測試檔 |
|---|---|---|
| load | sapolita SRT 的「華語：」列可能空白或整列缺，要讀成空字串不是漏掉一段；store 的 cue 要帶**真實**窗（`true_start`），SRT 的 0.5 秒留白會讓每條字幕看起來都跟鄰段重疊；同文相鄰 cue 會被組裝鏈併成一條，併掉的 cue 編號要留著（開會了 094 泰雅併掉 78 條）；新聞開頭 t=0 的色條 cue 要丟 | `test_load.py` |
| overlap | 字幕 0.1 秒溢出到下一段不可把兩段焊起來（「有重疊就併」在 656 集量到 31,249 組串過兩段、最長 495 秒，已刪）；剛好相接（end == start）不算重疊；平手歸前一段；字幕真的各佔兩段 40%／60% 才合併；★ 1.2 秒佔 4 秒字幕在浮點數裡是 0.2999…，剛好等於門檻也要算合併；沒對到對面的段落與字幕要分開回報，不可混進組裡 | `test_overlap.py` |
| textsim | 字幕寫「2000晚間新聞」、譯文寫「2000 晚間新聞。」——標點空白不能算差異；chrF 要偏召回（beta=2）；族語撇號三種寫法（ASCII、U+02BC、U+2019）要統一；字幕的長音記號 `^` `:`（「ho^」「Po:long」）辨識器從不輸出，比對前要拿掉；兩字母虛詞（o、no）對齊要留著，語言判定那邊丟 <3 字母是另一回事 | `test_textsim.py` |
| hallucination | 片尾配樂處整段「ʼa ʼa ʼa…」（144,806 段有 9.7%）；譯文「一、二、三、三、四…」數字串（38 段）；辭典比對要先統一撇號，否則「niyaroʼ」對不上「niyaro'」；太短的段不能判重複 | `test_hallucination.py` |
| goldalign | 辨識錯一個字母（sira／sera）仍要對上；漏一個詞要留空、不可整段位移；整段幻覺要對到零個詞、命中率 0；同樣的話 500 秒外也有，時間窗要擋住；沒有族語列的 cue（來賓講華語）不能當真值；三字母以下的短詞要完全相同才算（ho／hoo 是不同的詞） | `test_goldalign.py` |
| evaluate | 分數要按每條 cue 的詞數加權，一詞的跨界 cue 不能跟十詞的 cue 等重；多包一條 cue 掉精確率、少一條掉召回；併兩段的組要把兩段的真值合起來算；段落沒有真值要標出來不是算 0 分了事；AUC 平手算半分、一邊空要回 nan；門檻掃描要同時報好的留多少、壞的留多少 | `test_evaluate.py` |
| features | 全部特徵都要在**沒有標準答案的新聞**上算得出來；辭典命中率只數在辭典裡的詞；幻覺段的 chrF 是 0；時間覆蓋率要分「段落被字幕蓋多少」「字幕被段落蓋多少」兩個方向；長度比是族語詞數／華語字數 | `test_features.py` |
| lexicon（測 `news/lexicon_fetch.py`） | ★ sftp 的 `ls -l` 把中文檔名印成八進位跳脫（`\346\227\217…`），要解回 UTF-8 才認得出族名；★ 族名要從「_10邵語」那段讀——從檔名開頭找會先撞到「_16族」；檔名開頭日期改版會變，不可寫死；本機 16 族齊全就不連 SFTP；只缺一族就只抓那一族；抓不完整刪檔、指名中止；SFTP 上只有 15 族要指名缺哪族（別族判定 16 族互比，少一族那族的講者全被判命中率不足）；同一族本機有兩版要拒絕；xlsx 比詞庫快取新就重蒸餾；★ 測試用的詞不能帶數字，切詞會把數字當分隔 | `test_lexicon.py` |
| calibration | 卑南 0.17、魯凱 0.20 vs 卡那卡那富 0.67：基準按族；只算前 90 秒（後面訪談辨識差）、≥5 詞；表寫回讀回逐 byte 相同；讀回的是存下的四位小數；查無族語別要指名族與集中止，不可退回預設 0.5（實驗程式曾這樣寫）；沒有表要叫人先 --recalibrate | `test_calibration.py` |
| tier | 「harung uri」兩詞命中 1.0 → 詞數不足；別族講者本族命中率也過門檻照樣不採用；0.8 × 0.5 剛好等於門檻、chrF 剛好 0.02 都算過；卑南 0.12 是基準 0.17 的七成 → 中信心不是丟掉；原因優先序固定；合併門檻常數在這一支 | `test_tier.py` |
| features（補） | ★ 「幻覺」只指重複片段、譯文數字串、空白——實驗時把辭典命中率 < 0.2 也當可疑，卑南（基準 0.17）這種族會整批被當成幻覺丟掉 | `test_features.py` |
| pairs | 欄位先後照使用者指定、不採用原因在最後；時間戳「00:00:26,220」與族語結尾「sbaw,」含逗號，讀回一字不差；族語撇號 ʼ 原樣、多段用一個空格接；命中率與 chrF 三位小數；留下的列原因欄空白；UTF-8 無 BOM、LF、檔尾換行；重跑逐 byte 相同；零組也有表頭 | `test_pairs.py` |
| run（測 `news/pairs_run.py`） | 2021-11 兩側都有也不做；缺一側列出、不算錯；沒有校正基準表又沒下 --recalibrate 要拒絕；加一個月份，基準表與舊集數逐 byte 不變；--recalibrate 會覆寫表；片尾「ʼa ʼa ʼa…」那組判幻覺；不呼叫任何模型；合併門檻只從 tier 讀 | `test_run.py` |
| tuning | 1.2 秒佔 4 秒字幕在浮點數是 0.2999…，要落在 30–40% 那格；多條跨界字幕取最大的；0.5 剛好落最上面一格；三個版本只看這兩段、跨界字幕歸重疊多的那邊；一邊沒有字幕就沒有那一組；同種子抽到同一批（池的順序不影響）；不足 97 處全收並回報；合併版與拆開版不同批；一批 4 個 50 組；單列超過 1,800 字元不抽（Read 會截斷）；回覆少一列、標籤不對、編號重複或多出都整批退回；比「可用詞數」（高 1、中 0.5、低 0）；缺的一邊算 0；Wilson 區間（70/100 → 0.604–0.781）；一樣的不計；分不出取較低門檻；上面的格拆開較好就往上推；最上面一格也拆開較好就不合併 | `test_tuning.py` |
| pairs_tune（測 `news/pairs_tune.py`） | 抽樣寫出的合併版與拆開版在不同批；收件前先核對編號，不齊不搬進 accepted/；只統計收下的回覆 | `test_pairs_tune.py` |

跑法：

```bash
.tox/unittest/bin/python -m unittest discover -s tests/mt -t .
```
