# 族語新聞 burned-in 字幕 → SRT

把 `ilrdf-corpus/2月/*.mxf`（原視族語新聞播出母帶）裡燒在畫面上的中文字幕
抽成 SRT。影像處理本身由 `.claude/skills/video-subtitle-srt` 負責，這個目錄
只放這批語料專屬的東西：檔名對應、文稿校對、進度表。

程式與可重複使用的資料放這裡（會進 git）；產出的 SRT、work dir、log 放
`kithann/`（已被 `.gitignore` 排除）。

## 跑法

```bash
python3 ilrdf-srt/build_inventory.py      # 影片 → 節目資料 → SRT 檔名
bash    ilrdf-srt/run_cues.sh             # 切 cue ＋ tesseract（約 2.5 小時）
python3 ilrdf-srt/make_all.py             # 產 SRT ＋ 寫 kithann/srt/smkul.csv
```

`run_cues.sh` 會跳過已經有 `cues.json` 的 work dir，中斷後直接再跑一次即可。

## 幾個踩過的坑

**語料掛載點很慢。** `/dev/sda1` 是 NTFS-over-FUSE，實測單串流 41 MB/s、
雙串流 21+21 MB/s，也就是整顆碟就這樣。同時開三個解碼反而各自掉到
11.6 MB/s（慢 3.5 倍）。所以 `run_cues.sh` 改成：一次只循序複製一個檔到本機
磁碟（寫入 822 MB/s），解碼吃本機那份，解完就刪。380 GB 的讀取約 2.5 小時，
這是硬底線，解碼藏在它後面跑。

**檔名不可信，要用畫面驗證。** 五個 2021 年 2 月的檔名年份打成 `20`，
`21NL004_37午間` 掛的是晚間的 NL 代碼卻是午間。集數其實是「當年第幾天」
（集 32 ＝ 2 月 1 日），所以用「集數＋時段」查 `ilrdf-corpus.csv` 就夠。
時段取檔名裡的中文字，不取 NL 代碼；再把畫面左下角燒死的族語標章
（泰雅／撒奇萊雅／Seediq…）截出來跟目錄對照，24 個檔全部相符。

**上傳不完整的檔案。** 完整母帶是固定 6.30 MB/s 的 CBR。有兩個檔明顯偏低
（2.83 與 3.44 MB/s），檔頭仍宣稱完整長度，但尾端解碼毀損 —— 這兩集跳過。
只看 `ffprobe` 的 duration 看不出來，要拿位元組數除以長度才會現形。

## 文字從哪裡來

三個來源，品質差很多。實測基準是 46 個從 contact sheet 逐字讀出來的 cue：

| 來源 | 逐行完全正確 |
|---|---|
| tesseract | 26% |
| 文稿對齊（採用的部分） | **96%** |
| Claude 視覺辨識 | 全部正確 |

tesseract 讀這種壓在畫面上的中文很差
（`去年底桃園復興巴陵的一場大火` → `同/和)[人圖復興叫陜病一易大六`），
單獨用不能當語料。

**文稿對齊**（`align.py`）利用一件事：燒上去的字幕就是該集 `.rtf` 新聞稿的
內容斷行而成。tesseract 讀得爛，但不是亂讀 —— 對的字夠讓每個 cue 在稿子裡
定位，定位到了就用稿子的字。用 3-gram 投票找候選位置，再對整集解一次
最長遞增子序列，強迫「cue 往前、稿子也往前」，重複的詞就被鄰居票數壓過去。

會被丟掉的，比留下來的重要：

- **不做內插。** 兩個錨點之間按長度分配剩下的稿子，實測 0/9 全錯，
  而它們周圍的錨點是 25/28 對。新聞中間幾乎一定有稿子上沒有的東西
  （導言、標題、宣傳帶），一內插就整段錯位。
- **不切旁白段落。** 稿子裡受訪段落是一行一句字幕，可以整行拿（6/7 對）；
  旁白是一大段，只能照字元位置切，切出來是
  `000多種的植物種類。在`（正確為 `孕育出高達4000多種的植物種類`），
  實測 2/4。稿子沒有記錄旁白被斷在哪，所以寧可不給。

留下來的兩類：本來就對齊整句的（17/17）、以及吸附到稿子單行的（6/7）。

**視覺辨識**（plan B）是唯一全對的路，成本實測每張 contact sheet 約 3,450
tokens，一集 24 分鐘約 108 張、48 分鐘約 270 張。已完整做過
`20210212_043_午間_Rukai_魯凱`（430 cue 全數校讀）。做過的集數，
`make_all.py` 會直接採用視覺版，不再混入 tesseract。

## 檔案

| | |
|---|---|
| `build_inventory.py` | 影片↔節目資料對應，寫 `inventory.json` |
| `run_cues.sh` | 複製到本機 → 切 cue → tesseract |
| `wenkao.py` | 讀 Big5 RTF 文稿（檔頭寫 cp1252，其實是 Big5） |
| `align.py` | 把 OCR 結果對回文稿 |
| `make_srt.py` | 單集組裝 SRT |
| `make_all.py` | 全部組裝＋寫 `smkul.csv` |
| `check_align.py` | 拿手讀 TSV 量對齊的正確率 |
| `vision/*.tsv` | 視覺辨識逐字稿（可重複使用的成果） |

## 產出

- `kithann/srt/<播出日期>_<集數>_<時段>_<族語英>_<族語中>.srt` —— 每集一個
- `kithann/srt/wenkao-only/` —— 只含文稿對齊行的版本，適合直接入語料
- `kithann/srt/smkul.csv` —— 進度表，`字幕srt狀態` 註明每集文字的來源與比例
