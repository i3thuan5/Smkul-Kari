# 判定定義的歷版

`judge_prompt.md` 是**現在走的那一版**（subagent 讀的路徑固定在那裡）。這個資料夾留每一版的正文。

為什麼要留：判定快取（`Kari-SRT/news/2-asr/quality-cache/`）每一筆都記了版本。那個記號的意思是「這筆是照當時的定義判的」——定義沒留下來，記號就沒有意義，後來的人既看不出兩版差在哪，也重現不出那批判定。

原本是同一支檔案改了八次、每次直接覆蓋，磁碟上只剩最後一版。`tests/asrmt/test_prompt_versions.py` 現在會擋：**快取裡出現的版本，這裡一定要找得到。**

| v1 | 最初的三級定義，多靠語感 | 0／0／1 |

## 兩個教訓

**探針會通過一個把產出歸零的標準。** v7 三種探針全部零漏網，卻在真實資料上把某批的高打成 0——它的「前後條接得起來」在連續新聞稿裡永遠成立。探針的資料是一條條人工弄壞的、彼此獨立，不會誤觸。**驗證要兩種都跑**：探針量該擋的有沒有擋，真實資料量不該擋的有沒有被擋。

**agent 之間的差異和版本之間的差異一樣大。** 同一批 50 條、同一版，不同 agent 給的高是 0、3、6。單批比較不出版本好壞，要用整批的分布。
