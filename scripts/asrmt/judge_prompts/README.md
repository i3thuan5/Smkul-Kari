## 兩個教訓

**探針會通過一個把產出歸零的標準。** v7 三種探針全部零漏網，卻在真實資料上把某批的高打成 0——它的「前後條接得起來」在連續新聞稿裡永遠成立。探針的資料是一條條人工弄壞的、彼此獨立，不會誤觸。**驗證要兩種都跑**：探針量該擋的有沒有擋，真實資料量不該擋的有沒有被擋。

**agent 之間的差異和版本之間的差異一樣大。** 同一批 50 條、同一版，不同 agent 給的高是 0、3、6。單批比較不出版本好壞，要用整批的分布。

**整批判同一級（低）是 agent 沒在逐條判的記號。** 66 個回覆檔裡有兩個是 0高 0中 50低——阿美 032晚 s07、雅美 033晚 s13。同一集隔壁批的低只有 2% 到 14%；就算真的壞掉的區段（阿美 s08、s09、s10 低到 64%、84%、68%）也各留了 18、8、16 條中。**連一條中都沒有**才是破綻：低要逐條有正面的證據，50 條都有的機會太小。阿美 s07 換一個 agent 重判是 高0 中41 低9，證實原本那份有 41 條是假的。`ingest_reply` 現在會擋：一批十條以上而且每條都是低，整批退。只擋低不擋中——「無把握一律給中」是規則自己講的，整批中是合法結果（噶瑪蘭 s10 就是 0高 50中 0低）。

## 高的天花板是逐族不同的，不是標準鬆緊的問題

第一道關要有錨點，錨點來自借詞、數詞、專名、集內詞表四種。數詞表目前只寫了阿美、泰雅、噶瑪蘭三族；集內詞表是每集自己算的，薄的集只有一兩筆。所以能不能拿高，看的是那一集有多少可查證的東西：

| 集 | 詞表筆數 | 高 |
|---|---|---|
| 泰雅 032午 | 9 | 36 |
| 噶瑪蘭 033午 | 11 | 23 |
| 雅美 033晚 | 2 | 12（第一輪）|
| 魯凱 001午 | 0 | 9（第一輪，靠借詞）|

十六族裡多數會落在魯凱這一端。這不是判太嚴——是那些族的資料裡本來就沒有東西可以拿來互證。要拉高只有一條路：把十六族的數詞表都補進規則裡，那就是新的一版，而且已判的全部要重判。
