## 這是什麼工作

## 判讀方法（踏過ê坑攏寫佇遮）

**1. 圖條看無準，一定愛抽原生格。** 圖條是規段ê中位數合成ê，短句會予洗掉。定案愛用真ê影格：

```bash
ffmpeg -nostdin -v error -copyts -ss <起點> -t <長度> -i 影片 \
  -vf "select='between(t,<開始>,<結束>)',crop=1920:122:0:722" \
  -vsync 0 -frame_pts 1 -f image2 out/f_%d.png
```

- **`-ss` 一定愛囥佇 `-i` 頭前，閣愛有 `-copyts`。** `-ss` 囥後壁是概略 seek，5 fps ê時有 ±1 格ê誤差，捌害 13 个判定顛倒反。頭一擺請用三个無仝ê `-ss` 起點（比論 3／12／25 秒）抽仝一格，md5 相同才閣落去。
- **`-nostdin` 袂使無。** 無ê話 ffmpeg 會kā `while read` 迴圈ê輸入食去，逐段對著ê時間全走位。
- **`-t` 嘛袂使無。** 無ê話 `select` 篩了後 ffmpeg 猶原解碼到檔尾，逐段對 22 秒；有 `-t` 才 1.8 秒。
- **`-frame_pts 1` 出來ê數字是「格號」，毋是毫秒。** 秒數＝`格號 × 1001 / 30000`。
- **`between(t, …)` ê秒數愛先量化到毫秒，而且愛用整數算。** mkv ê
  時間戳是 1 ms ê網格，直接提 `n*1001/30000` 這款無量化ê秒數去比，
  **會漏掉將近一半ê格**，而且 ffmpeg 是恬恬回 0，無報錯。閣有，
  **`round(n*1001/30000, 3)` 猶原無夠**：Python ê `round()` 是五成
  雙，muxer 是四捨五入，拄好 .5 ê格會差 1 ms（頭 3000 格內底有 55
  格按呢，間隔 60/30 相間）。愛用整數：

  ```python
  ms = (2 * n * 1001 + 30) // 60      # ＝ floor(n*1001/30 + 0.5)
  lo, hi = (ms - 0.4) / 1000, (ms + 0.4) / 1000
  ```

**1之二. 「文化小辭典」段ê字幕會沉落去，標準 crop 切無著。** 彼款段
規个節目縮做子母畫面，字幕落到 **y≈825–885**，標準ê `1920:122:0:722`
干焦切著頂懸約 19 px。認法：**遮罩ê ink 忽然掉到 600–2200**（別位
是 5000–20000）。拄著就改用較懸ê crop：

```
crop=1920:200:0:700
```

原本ê管線嘛是按呢漏去ê，所以遮ê cue 既有真可能是空ê抑是毋著ê。
**莫掠做「無字」。**（20210208_039晚 cue 273/285/286/302/319 就是。）

**1之三. 順紲量一下字幕實際佇第幾列，報予我。** 你本底就有抽原生
格，加這步差不多免錢：揀 5 格有字ê，用 `scripts/ocr/cuelib.py` ê
`text_mask`（spec 對該集 `cues.json` ê `mask` 鍵讀）算**逐列ê ink
剖面**，講字ê峰佇 y 幾到幾（絕對座標，crop 記得換算轉去）。

**字幕有兩个列位**（122 列ê帶拄好囥會落兩逝）。四集ê實測：

|---|---|---|

| 20210209_040午 | 60 段（y 729–778） | 48 段（y 787–836） |
| 20210221_052午 | 118 段（y 728–779） | 65 段（y 786–837） |

8 段懸沿，**8 段攏佇 t=468–631 秒仝一則記者包內底**，棚內訪談佮片尾

底有幾則包用兩逝版型爾爾。

（捌有「午間有兩沿、晚間無」ê假說：頭 6 集看起來成立，20210217_048午
先推翻一半（午間煞 0 懸沿），20210216_047晚 閣推翻賰彼半（晚間嘛會
有）。**時段推袂準，愛逐條 cue 家己量。**）

**位置真穩定**（懸沿字底 ~778、下沿字底 ~836），**比例完全無穩定**
（0% 到 64% 攏有），所以袂使規集固定用一沿。按呢：

- **抽格ê crop 用 `crop=1920:204:0:700`（y 700–904）。** 較狹ê
  `1920:150:0:770` 會kā懸沿彼幾逝剁掉；**`1920:180:0:700`（y
  700–880）嘛無夠**——子母畫面段ê字會予剁去下半截（20210219_050晚
  11 段就按呢，愛到 y≈902 才看會著規字）。
- **Crop 愛闊，判準愛狹：算 ink／遮罩ê時，列愛限佇 y ≤ 845。**
  下三分之一彼條紅帶ê懸低**逐集會走**——20210210_041晚 ê紅帶對
  y≈848 就起、字佇 865–900（名牌閣佇 905–1000），攏落佇 crop 內
  底。判準若無限，紅帶ê字就會予算做字幕。「930–1004 是超文字」
  彼个數字是頭幾集量ê，**莫死記**，愛看該集家己ê剖面。
- **懸沿無一定是對白。** 20210213_044晨 ê懸沿規片予「畫面提供:…」
  彼款上字占去（9 段、2000 格），一段對白都無。看著懸沿有物件ê
  時，先判伊是對白抑是上字。
- 算判準ê時，**上好先看該條 cue 是佇佗一沿**（量伊家己ê ink 剖
  面），才干焦提彼一沿ê列來比——另外彼沿是背景，會kā分母灌大。

你ê數字報予我，逐集積起來就知影兩沿ê比例佮位置敢有穩定。

**2. 上緊ê做法：取「涵蓋中點彼格」。** 一段內底**若干焦換一擺句**，涵蓋中點彼格照定義就是佔多數彼句。逐段先按呢定案，紲落來才對可疑ê補查。

**毋過三个狀態以上就無這个保證。** 比論 20210207_038晨 段 830.05：
燻乾 0.23 秒 → 無字 0.20 秒 → 磨成粉 0.37 秒，**中點彼格是空白**，
相對多數煞是「磨成粉」。所以中點格干焦是**頭一步ê定案**，段內若
掠著換句超過一擺，一定愛倒轉去算秒數。

**3. 分界判準莫用 Jaccard（`cuelib.mask_distance`）家己定案。** 伊除ê是聯集，亮背景（報紙、氣象圖、白布條）kā分母灌大，換句就予稀釋去——20210201_032午 cue 17 ê距離才 0.346，掉佇 0.35 門檻下。**分母莫予背景牽連**ê做法分會開：相鄰格遮罩ê **XOR 絕對像素數**（靜止背景貢獻是零），抑是**對參考格ê召回率** `|ref ∩ frame| / |ref|`。這兩款佇 20210201_032午 攏無漏。

**毋過 XOR 若配「穩定遮罩」（前後幾格 AND）掃，掠著ê邊界會早
大約 0.13 秒**（AND 窗口ê偏差）。穩定遮罩提來**揀嫌疑段**就好；
真正欲判多數ê時，愛用**原生遮罩**對頭格／尾格ê XOR 交叉點重掠換
句時間。差 0.13 秒佇 0.4 秒ê段內底就是判反。

**第三款判準：相鄰格遮罩ê交集像素數 `|mask_i ∩ mask_{i+1}|`。**
背景若振動傷厲害（20210221_052午 244 段內底 XOR 有 204 段報警，
無路用），改看交集：仝一句ê時交集就是字形本身（5,000–20,000 px），
換句ê時掉到 1,000–3,000。門檻用「低過該段 P75 ê 0.70」。

**召回率有兩个盲點，愛配別項用：**

- **對「加字」是盲ê。** 新字若是舊字ê超集（字幕閣接一逝、抑是
  加詞），召回率顛倒是 1.0。愛另外掠「殘差ê絕對像素數 ≥1200」。
- **亮閣靜止ê背景之下猶原會失效。** 背景佔遮罩絕大部份ê時，兩句
  無仝ê四字句召回率會到 0.79（20210204_035晚 cue 1150，攝影棚白
  底）。彼陣愛**逐格減去段內 88% 以上攏著ê靜止遮罩**，賰ê殘差才
  分群，閣要求換句是**單向ê**（標籤袂閣越轉來）。

**4. 一段內底若無仝句超過一擺**，逐格歸予上倚ê參考格，算出實際換句點佮逐句佔ê秒數，照下底ê順序判：

1. 佔絕對多數ê彼句
2. 無絕對多數ê時，佔相對多數ê
3. 兩句差 **< 0.05 秒**ê時，**報出來予我看**；若換句點拄好佇該段中央（揀佗一句界線攏偏仝款濟），就照第 2 條相對多數判，**莫留「／」佇檔案內底**
4. 有一句「兩爿攏無厝」（頭尾兩段攏無伊）ê時，寫入伊佔上濟彼段

**5. 一段內底ê句比一格通寫ê閣濟ê時。** 兩款情形：

- **規段切袂開**（亮閣無振動ê背景，遮罩變無到 7%，切段器卡牢）：
  20210219_050 cue 1115、20210201_032午 cue 1061、20210204_035晚
  cue 1150 攏是。
- **切會開矣，毋過一段內底猶有三句**（`reread` 切了無夠幼）：
  20210204_035晚 頭 100 逝內底就有四段按呢。

兩款攏**先看賰ê彼幾句佇別段抑是厝邊 cue 有厝無**：

- **有厝**——寫多數句就好，佇報告內底講。
- **無厝**——**照實kā相黏寫入彼格**，佇報告內底特別講。相黏歹看，
  毋過規句無去是袂補ê。


**6. 字幕帶內底毋是對白ê物件，留空。** 片尾跑馬職稱、「文化小辭典」ê超文字（伊佇 y≈940–1010，佇 crop 下底）、畫面提供／受訪者名牌。判準是**看伊是毋是有人講出來ê話**；無把握就看既有彼幾條是毋是嘛空ê。

**7. 字幕帶內底ê羅馬字**（無漢字彼款）**是字幕，愛讀入去。** 燒印字幕
主要是漢字，毋過全批有 231 格（0.45%、20 集）是純羅馬字——地名、
歌名、人名，閣有規句ê族語。**莫kā「無漢字」當做「毋是字幕」。**
