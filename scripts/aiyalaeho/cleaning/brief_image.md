# 開會了族語字幕清洗：看圖判準

《開會了》的族語字幕是電視台燒在畫面上的，經視覺辨識讀成文字。文字分類判成「錯字」的地方，以及彎撇號 `’` 後面夾空白的地方，要回頭看**原生圖條**，分清楚是畫面本來就這樣（電視台打錯），還是我們讀錯。

## 你的任務

讀 `待判-bNN.csv`，每一列是一處（某一集某一條字幕裡的一個詞）。用 Read 工具打開「圖條」欄列出的每一張 PNG（族語列的原生圖條，1920×60），對照族語列文字，寫結果到同資料夾的 `bNN.csv`。

一條字幕可能由好幾個 cue 組成，圖條欄會用分號列出好幾張，**每一張都要看**。

## 輸入欄位

| 欄 | 意思 |
|---|---|
| 成果檔名、字幕編號 | 哪一集哪一條 |
| 詞形 | 要確認的那個詞（原樣） |
| 建議寫法 | 文字分類給的正確寫法；撇號那類是「把空白併掉」的寫法 |
| 族語列、華語列 | 這條字幕的兩列文字 |
| 圖條 | 族語列原生圖條路徑，分號分隔 |

## 三個類別

| 類別 | 什麼時候用 | 畫面上的寫法 |
|---|---|---|
| OCR 讀錯 | 畫面上的字和「詞形」不一樣，是讀字讀錯了 | **必填**，照畫面寫出正確的字 |
| 播出端錯字 | 畫面上就是「詞形」那樣，是電視台打錯 | 照畫面寫 |
| 看不出來 | 圖太模糊、被遮住、或看了也無法確定 | 可空白 |

播出端（電視台）打錯的字也會訂正成建議寫法，所以請如實判斷，不要因為「畫面就是這樣」而手軟。

## 彎撇號夾空白

詞形像 `mena’   u`、`’  san` 這種，是畫面上的彎撇號 `’` 後面有一段空隙。請判斷撇號前後是不是**同一個詞**：

- 是同一個詞（空隙只是字型的字距）：類別寫「播出端錯字」，畫面上的寫法寫**併起來、用直撇號**的寫法，例如 `mena'u`。
- 確實是兩個詞（空隙是詞和詞之間的空白）：類別寫「播出端錯字」，畫面上的寫法寫**分開、用直撇號**的寫法，例如 `mena' u`。
- 只改「詞形」那一段，不要把前後的詞寫進來。
- 看不出來：類別寫「看不出來」。

## 輸出格式

`bNN.csv`，UTF-8 無 BOM，第一列是表頭：

```
成果檔名,字幕編號,詞形,類別,畫面上的寫法,理由
開會了_087_Pinuyumayan_卑南,188,Likavungg,播出端錯字,Likavungg,畫面上確實是兩個 g
開會了_087_Pinuyumayan_卑南,376,mena’   u,播出端錯字,mena'u,彎撇加字距，同一個詞
```

- 每一個待判列都要有一列；成果檔名、字幕編號、詞形**照抄**，不能多也不能少。
- 類別只能是上面三個之一。
- 理由用華語（正體字），一句話，40 字以內。
- 含逗號的欄位要用雙引號括起來。
