# 開會了族語字幕清洗：文字分類判準

你是在幫原住民族語言電視節目《開會了》的字幕做清洗。這批字幕是電視台自己打在畫面上的族語（阿美、泰雅、卑南、賽夏），由視覺辨識讀成文字。程式已經把每個族語詞形拿去比對官方辭典、族語E樂園（分語別的教材）和語音模型詞表，**哪裡都查不到的詞**才送來給你判。

## 你的任務

讀 `待判-bNN.csv`，每一列一個詞形，判它屬於哪一類，寫到同資料夾的 `bNN.csv`（批號相同，去掉「待判-」）。

## 輸入欄位

| 欄 | 意思 |
|---|---|
| 詞形 | 字幕上的寫法（原樣，含大小寫） |
| 出現集數 | 在哪幾集出現（三位數集數） |
| 該集語別 | 程式推測這幾集講的是哪個語別（例：西群;知本）；空白表示該族只有一個語別 |
| 辭典 | 官方辭典有沒有收（辭典一族只收一個語別：阿美秀姑巒、泰雅賽考利克、卑南南王） |
| E樂園見過的語別 | 族語E樂園哪些語別的教材出現過這個詞 |
| Kaldi詞表 | 語音模型詞表有沒有 |
| 最接近的辭典詞條 | 辭典裡只差一個字母的詞 |
| 相近寫法 | 字幕裡只差一個字母的其他寫法，括號是開會了各集出現次數 |
| 上下文 | 最多三句：`集數#字幕編號 族語：…／華語：…` |

## 五個類別

| 類別 | 什麼時候用 | 建議寫法 |
|---|---|---|
| 錯字 | 明顯打錯或讀錯：多一個字母、少一個字母、字母順序錯、喉塞音 `'` 漏掉，而且看得出正確的應該是哪個詞（通常是相近寫法或最接近的辭典詞條，華語列的意思也對得上） | **必填**，寫正確的寫法（保留原本的大小寫習慣，句首大寫照舊） |
| 語言別差異 | 這個寫法是該集語別或其他語別的正常形式，只是辭典或教材沒收（例：卑南南王 garem、西群 harem） | 空白 |
| 不同詞 | 是一個正常的詞（人名、地名、借詞、加了詞綴的變化形），只是哪裡都沒收；相近寫法是別的詞 | 空白 |
| 斷詞不同 | 附著詞黏在一起或一個詞被拆開（例：marengayakuziya 把 ku、ziya 黏上去） | 可填分開或合起來的寫法，供討論 |
| 不確定 | 看不出是哪一種 | 空白 |

**原則：**

- 明顯就判錯字，**不確定就判不確定**，不要猜。判錯的語言別差異會被改掉，傷害比漏判一個錯字大。
- 語言別差異**不算錯字**。辭典只收一個語別，和辭典不同不代表錯。
- 播出端（電視台）打錯的字也要訂正：判錯字、給建議寫法。之後會再看圖確認是電視台打錯還是辨識讀錯，兩種都會訂正。
- 不要改字母系統：`^ ' " : ʉ` 都是正字法的一部分。冒號是長音或詞的一部分，不是標點。
- 族名、部落名、人名等專有名詞，相近寫法裡有大寫的常見寫法時，多一個或少一個字母通常是錯字（例：Likavungg → Likavung，華語是利嘉部落）。

## 輸出格式

`bNN.csv`，UTF-8 無 BOM，第一列是表頭：

```
詞形,類別,建議寫法,理由
Likavungg,錯字,Likavung,同集另寫 Likavung 10 次，華語是利嘉部落；多打一個 g
harum,不確定,,相近 harem 是西群寫法，但上下文看不出是否同一詞
```

- 每一個待判列都要有一列，**詞形照抄**（一個字元都不能改），不能多也不能少。
- 類別只能是上面五個之一。
- 理由用華語（正體字），一句話，40 字以內，寫出你的依據。
- 含逗號的欄位要用雙引號括起來。
